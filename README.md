# South-status-monitor
監控南+註冊頁面是否開放(懶人用)

## 功能說明

* **自動定時監控**：可自由設定檢查間隔秒數（預設 180 秒），定時向目標網頁發送請求。
* **智慧條件觸發**：當偵測到網頁開放或解除限制時，會自動彈出提示、發出警報聲，並自動開啟預設瀏覽器跳轉。
* **背景系統托盤**：支援最小化或關閉視窗時縮小至系統匣（通知列），背景靜默運行不佔工作列空間。
* **即時日誌視窗**：內建深色主題 Log 輸出框，可隨時查看每次檢查狀態、回應字節數與執行記錄。


⚙️ 設定與 Debug 功能
* **齒輪設定按鈕**：可自訂點擊最小化與關閉按鈕時的行為（縮小至工作列或系統托盤）。
* **Debug 模式**：勾選後會在程式同目錄下自動儲存目前抓取到的網頁狀態，原始碼為 `debug_page.html`。
* **防呆與穩定機制**：具備網路逾時保護、防重複執行鎖及完整例外防護，確保長時間監控穩定。
